# Money Storm BR - Aplicativo de Recompensas

Este é um aplicativo mobile focado em engajamento de usuários através de um sistema de pontos e recompensas, desenvolvido com React e otimizado para dispositivos Android.

## 🚀 Funcionalidades
- **Sistema de Pontuação:** Acúmulo de pontos por atividades.
- **Resgates via Pix:** Integração para solicitações de pagamento seguras.
- **Monetização Híbrida:** Exibição de anúncios premiados via Unity SDK e Monetag.
- **Ofertas de Afiliados:** Integração com a rede Lomadee para ofertas exclusivas.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React.js
- **Hospedagem Web:** Base44 (cash-pix-go.base44.app)
- **Build Mobile:** GitHub Actions (Geração de APK automática)

## 📱 Como gerar o APK
O projeto está configurado para gerar o pacote Android (.apk) automaticamente através das GitHub Actions a cada atualização na branch principal.
